<summary>Click to view</summary>

- Download dependencies by running `npm install`
- Start up the app using `npm run dev`
</details>

### Completion Instructions

<details>
<summary>Functionality to be achieved</summary>
<br/>

- Initially, both pending tasks and completed tasks count should be `0`
- When the **Add Task** button is clicked, then the pending tasks count should
  be incremented by one
- When the **Complete Task** button is clicked and there are pending tasks:
  - The pending tasks count should be decremented by one
  - The completed tasks count should be incremented by one
- When the **Complete Task** button is clicked with no pending tasks, the counts
  should remain unchanged

</details>
